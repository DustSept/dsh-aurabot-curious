# 不懂就问 · Aurabot 模块

给 [Aurabot](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq) 加一点“不知道就问”的真实感：遇到没听过的新词、新梗、新领域时，有一定概率不装懂，先问清楚或猜一下再问。

模块 ID：`curious` · 扩展接口：v1 · 版本：1.0.0

## 功能

- **概率触发**：不是每轮都装傻，默认大约 25% 的聊天会加一条“可能不懂”的内心提示。
- **先查上下文**：触发前会看当天聊天流水和长期记忆；刚提过的东西不会“刚说完又问”。
- **两种反应**：
  - 直接问“这是什么”“你从哪听来的”；
  - 先按自己的理解猜一个，再问“是……吗”。
- **冷却时间**：同一个聊天触发一次后，默认 8 分钟内不再触发。
- **默认只在私聊**：群里人多，避免每句话都问“这是什么”。
- **不改人设**：只加一条内心提示，不会强制她装傻；她其实熟就正常接。

## 安装

需要 Windows、Aurabot 1.0.5+（扩展接口 v1）。

把本仓库的 `curious` 文件夹复制到：

```
%USERPROFILE%\.dsh\plugins-data\aurabot\modules\curious
```

正确结构：

```
modules\curious\index.mjs
```

等几秒自动加载，打开面板「扩展」页，应该能看到「不懂就问」在跑。

## 建议加人格片段

模块本身能用，但把 [`persona/curious-section.md`](persona/curious-section.md) 粘到人格卡里，她的语气会更自然：

```markdown
【不懂就问】
- 遇到不熟悉的新词、新梗、没听过的事，不要装懂，也不要给百科式定义；可以先问「这是什么」「你从哪听来的」，或者猜一下再问对不对。
- 如果你其实很熟，就正常接，不要为了装傻而装傻。
```

## 设置

面板「不懂就问」页：

| 设置 | 默认 | 说明 |
|---|---|---|
| 开关 | 开 | 关掉后她恢复“什么都懂”的状态 |
| 每轮触发概率 | 0.25 | 0 到 1，大约四分之一的对话会提醒 |
| 同一聊天冷却（分钟） | 8 | 触发一次后多久不再提醒 |
| 先查上下文/记忆 | 开 | 刚提过/记忆里有的词不装不懂 |
| 只在私聊 | 开 | 群聊人多，建议保持开启 |
| 不懂时的反应 | 随机 | `随机` / `直接问` / `先猜再问` |

## 怎么判断“懂不懂”

触发时：

1. 取当天这个聊天的最近 80 条聊天流水，排除当前这句；
2. 用 `memory.list(这句话)` 取最多 8 条相关长期记忆；
3. 从这句话里切出 2–4 字的词，去掉“什么/怎么/这个/那个”等常用词；
4. 如果聊天或记忆里出现过 **3 字以上**的重合词，就认为“刚聊过/知道”，跳过；
5. 否则按概率加一条内心提示。

只看 3 字以上的词，是为了避免“天气”“研究”这种常用词造成误判。

## 适合的对话

| 你说 | 她可能 |
|---|---|
| “鲸鱼天气学是研究什么的” | 先问“这是什么，你从哪听来的” |
| “量子纠缠到底是什么” | 先猜一个，再问“是……吗” |
| “孤儿远征军” | 如果记忆/聊天里出现过，就正常接，不装不懂 |
| “今天好热” | 普通聊天，不触发 |

## 已知限制

- 只查**当天聊天流水 + 长期记忆**；昨天别的聊天里出现、又没进长期记忆的话题，可能被当成新话题。
- 概率触发，不是每轮都问；想更常问就把概率调高。
- 3 字以上才算“知道”，有些很新的短词可能被漏判；可以关掉「先查上下文」只按概率。
- 它不会联网搜索，也不会强行拒答；只是给她一个“可能不懂”的提示，具体怎么接仍由她决定。
- 群聊默认关闭；打开后建议把概率调低。

## 调试

装上后可以访问（本机）：

```
/aurabot/api/ext/curious/check?text=鲸鱼天气学是研究什么的
```

返回 `known` 和切出来的 `terms`，方便看某个话题会不会被判定为“刚聊过”。

## 安全

- 只读本机聊天流水和记忆，不联网、不读 API Key、不发消息。
- 提示会作为当前轮上下文的一部分发给模型；没有额外服务。
